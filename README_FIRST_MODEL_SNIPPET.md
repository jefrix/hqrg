# README Snippet: First Calculable Model Result

The first Path A calculable model studies whether an effective 4D informational scalar \(\phi\) could shift the hidden-order transition temperature in URu₂Si₂.

The Landau-level result is

\[
\delta T_{\rm HO}
=
-\frac{\lambda_{\phi\psi}\langle\phi\rangle}{a}.
\]

This means URu₂Si₂ data constrain the product \(\lambda_{\phi\psi}\langle\phi\rangle/a\), not the scalar coupling, background field, or fifth-force parameter separately.

The corrected conclusion is:

\[
|\delta T_{\rm HO}|_{\rm phen}
\lesssim
10\text{--}50\,{\rm mK}
\]

as a phenomenological material sensitivity target, while

\[
|\delta T_{\rm HO}|_{\rm fifth-force}
\lesssim
10^{-19}\,{\rm K}
\]

if \(\phi\) is an ordinary unscreened long-range scalar whose coupling tracks ordinary matter.

Therefore a detectable URu₂Si₂ signal would require a non-generic HQR mechanism: screening, material-specific coupling, topological hidden-order coupling, or correlated observables.
