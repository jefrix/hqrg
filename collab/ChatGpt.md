## Why This Lane

The first calculable model produced a useful negative result:

> A detectable mK-scale shift in URu₂Si₂ cannot be generated by a generic unscreened long-range scalar obeying existing fifth-force/equivalence-principle constraints.

That is not a failure. It is a filter.

It tells us that HQR must become more distinctive than generic scalar-tensor gravity.

The next calculable model should therefore explore a mechanism where the scalar does **not** couple mainly to ordinary baryonic matter, but instead couples to one of the following:

1. the hidden-order condensate,
2. strain / lattice distortion,
3. anisotropic susceptibility,
4. spin-orbit / multipolar order,
5. a topological density associated with the ordered phase,
6. a screened effective source active only inside the correlated-electron medium.

This is also more consistent with the Path A discipline: \(\phi\) remains a postulated phenomenological scalar, but its material coupling is made explicit and testable.

## Proposed Model Structure

I suggest the new file use the following structure.

### 1. Start from the Path A 4D scalar model

Use the existing Landau result:

\[
\delta T_{\rm HO}
=
-\frac{\lambda_{\phi\psi}\langle\phi\rangle}{a}.
\]

Then state that the universal unscreened scalar case is already suppressed by fifth-force bounds and is not the target.

### 2. Introduce a screened/material effective coupling

Replace the universal coupling with an effective material coupling:

\[
\lambda_{\phi\psi}^{\rm eff}
=
\lambda_0\,\mathcal{S}_{\rm mat}(T,P,B,\epsilon,\chi,\Delta_{\rm HO}),
\]

where:

- \(T\) is temperature,
- \(P\) is pressure,
- \(B\) is magnetic field,
- \(\epsilon\) is strain,
- \(\chi\) is susceptibility,
- \(\Delta_{\rm HO}\) is the hidden-order gap or order-parameter scale,
- \(\mathcal{S}_{\rm mat}\) is a material response/screening function.

Then the measurable shift becomes

\[
\delta T_{\rm HO}(P,B,\epsilon)
=
-\frac{\lambda_{\phi\psi}^{\rm eff}(P,B,\epsilon)\langle\phi\rangle}{a}.
\]

This turns the target from a single absolute shift into a correlated pattern.

### 3. Add a screening equation for \(\phi\)

Use a simple environmental scalar equation:

\[
\left(
\nabla^2-m_{\rm eff}^2({\rm env})
\right)\phi
=
J_{\rm HO},
\]

with

\[
J_{\rm HO}
=
q_\psi |\psi|^2
+q_\epsilon \epsilon_{ij}\epsilon^{ij}
+q_\chi \chi_{ij}\chi^{ij}
+q_{\rm top}\mathcal{Q}_{\rm top}.
\]

Here \(J_{\rm HO}\) is not ordinary mass density. It is a hidden-order/material source.

This is the key evasion mechanism: fifth-force tests constrain couplings to ordinary matter sources, while this model tests a coupling to a condensed-matter hidden-order source.

### 4. Define the observable vector

Instead of treating \(\delta T_{\rm HO}\) alone as the signal, define

\[
\vec{\mathcal{O}}_{\rm HO}
=
\left(
\delta T_{\rm HO},
\delta\Delta C,
\delta\Delta S,
\delta\chi_{ab},
\delta\chi_c,
\delta\omega_{\rm neutron},
\delta T_{\rm HO}(P,B,\epsilon)
\right).
\]

HQR becomes more distinctive if it predicts a constrained pattern across this vector.

### 5. Derive a falsifiability condition

The model should require:

\[
|\delta T_{\rm HO}|_{\rm universal}
\ll 1\,{\rm mK}
\]

but allow, only through material/topological coupling,

\[
|\delta T_{\rm HO}|_{\rm material}
\sim 1\text{--}50\,{\rm mK}.
\]

The falsifiability statement should be:

> If the only allowed Path A scalar coupling is universal and unscreened, then URu₂Si₂ is not a viable detectable testbed for HQR. If HQR is to remain testable in URu₂Si₂, it must specify a screened, material-specific, or topological source term whose response differs from ordinary matter coupling.
